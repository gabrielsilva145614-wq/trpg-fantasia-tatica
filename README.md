# TRPG Fantasia Tática - Campanha Infinita

## Sobre o Projeto

TRPG Fantasia Tática - Campanha Infinita é um jogo de RPG tático desenvolvido em Python utilizando a biblioteca Pygame.

O jogador controla uma equipe de heróis em batalhas estratégicas por turnos contra diversos inimigos. Cada personagem possui atributos, habilidades e estilos de combate únicos.

O projeto foi desenvolvido para aplicar conceitos de programação orientada a objetos, algoritmos de busca, inteligência artificial, geração procedural de mapas e desenvolvimento de jogos utilizando Python.

## Funcionalidades

* Combate tático por turnos
* Sistema de movimentação em grade
* Diversas classes de heróis
* Habilidades especiais exclusivas
* Sistema de progressão por níveis
* Loja para compra de personagens
* Inteligência artificial para inimigos
* Geração aleatória de mapas
* Sistema de recompensas
* Armadilhas e efeitos especiais
* Console de comandos para testes

## Tecnologias Utilizadas

* Python 3
* Pygame
* Random
* Collections (deque)
